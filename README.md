# Python Utility Module

A simple and reusable Python utility module that provides commonly used mathematical functions. The module includes functions to calculate the factorial of a number, find the square root, and check whether a number is prime.

## Features

* Calculate the factorial of a number
* Calculate the square root of a number
* Check whether a number is prime
* Simple and reusable Python functions
* Beginner-friendly implementation

## Purpose

This project is designed to demonstrate how mathematical utility functions can be organized into a reusable Python module.
